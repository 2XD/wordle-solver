# Wordle Solver

A Wordle solver I made because I was bored and wanted to test if the internet geniuses were correct about "SALET" being the best first guess (spoiler it isnt)

## What it does

- Uses the official Wordle answer list and allowed guesses
- Filters possible answers
- Recommends the best next guesses
- Can use guesses that aren't possible answers if they give better information
- Pretty cool gui

## How to start app

Run:

```bash
python wordle.py --gui
